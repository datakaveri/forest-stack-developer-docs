# Login & Organization Membership

Managing user access and organisational membership is essential to ensuring trusted participation and secure onboarding within Forest Stack. This section introduces the identity flow that supports users as they create accounts, sign in, recover passwords, and join registered organisations on the platform.

---

## User Account Basics

The user journey begins with a few essential steps:

- **Registration**
- **Login**
- **Password Recovery**

These workflows allow individuals to securely access Forest Stack and begin exploring available datasets, models, and use cases. Every newly registered user is automatically assigned the **Consumer** role, which provides access to general browsing and discovery features.

---

## Joining an Organisation

To contribute assets such as datasets, models, or use cases, a user must be affiliated with a **Data Provider Entity**. Forest Stack supports an eKYC-like validation process to ensure that only authorised individuals gain provider-level permissions.

Users can elevate their role by:

### **Joining an Existing Data Provider Entity**
Users may request to join an organisation already registered on Forest Stack.  
The request is reviewed and approved by that organisation’s **Organisation Manager**, who validates the user’s association and assigns the appropriate provider permissions.

---

## A Secure and Accountable Membership Flow

By requiring organisation membership for provider roles, Forest Stack ensures accountability for all published content and maintains a secure governance structure.  
The pages that follow detail each step of these workflows - helping users onboard, authenticate, and seamlessly participate as authorised members within Forest Stack.
