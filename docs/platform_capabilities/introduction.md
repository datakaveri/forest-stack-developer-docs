# Platform Capabilities

Forest Stack offers a unified environment where users can explore, contribute, and apply three core asset types **Datasets**, **Models**, and **Use Cases** to drive data-driven governance, research, and innovation. This section provides an overview of how the platform enables seamless discovery, efficient asset management, and the practical application of Models and data resources.

---

## Discovering Platform Assets

Users can browse comprehensive listings of Datasets, Models, and Use Cases through intuitive interfaces equipped with:

- Search bars
- Sorting tools
- Advanced filter panels
- Detailed metadata previews

These tools help users quickly identify relevant resources based on domain, organisation type, permissions, file formats, industries, update timelines, and more.

---

## Contributing Assets

Forest Stack streamlines the upload and publication workflows for Providers and Organisation Managers. Each asset type follows a structured contribution process that includes:

- Entering metadata
- Uploading files or providing links
- Linking related assets
- Submitting for approval

This standardised workflow promotes consistency, quality, and accountability across all published content.

---

## Accessing & Downloading Assets

Downloading assets is designed to be straightforward:

- **Open assets** are immediately accessible to all registered users.
- **Restricted assets** require approval before download, ensuring responsible and compliant data access.

---

## Use Cases: Applying Data & Models

Use Cases showcase real-world applications, illustrating how Forest Stack’s datasets and models can be combined to address practical challenges. These examples help users:

- Understand potential applications
- Explore new ideas

---

## A Complete Ecosystem

Together, these capabilities make Forest Stack a complete ecosystem for data discovery, model deployment, and AI-driven problem-solving across diverse domains. The pages that follow explore each capability in detail—helping users make the most of the platform’s resources.
