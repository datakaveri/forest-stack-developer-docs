# Platform Administration

Platform Administration in Forest Stack provides a structured suite of tools that enable Central Operating System (COS) administrators to oversee users, organisations, and assets across the platform. These controls ensure secure access management, validated organisational onboarding, and responsible contribution workflows maintaining the overall integrity and reliability of Forest Stack’s data and AI ecosystem.

---

## User Oversight

Administrators can monitor platform usage through:

- **User Activities** – Detailed logs of user interactions with assets
- **User Management** – Tools to activate/deactivate users and view user information

These capabilities help administrators track platform engagement and maintain secure, well-governed access.

---

## Organisation Management

COS administrators are responsible for validating and maintaining all **Data Provider Entities**. This includes:

- Reviewing and approving new organisation requests
- Verifying submitted documentation
- Maintaining up-to-date records for existing entities

Only trusted and authorised organisations are permitted to publish datasets, models, and use cases.

---

## Asset Management

Asset Management offers complete oversight of all contributions made to Forest Stack. Administrators can:

- View and verify submitted datasets, models, and use cases
- Edit asset metadata
- Hide or unhide assets
- Permanently delete inaccurate or non-compliant content

COS admins also review dataset upload requests submitted via **SFTP** or **API**, ensuring that published content adheres to platform standards. Additionally, they can contribute use cases through the **My Contributions** tab, learn more about adding a use case in its dedicated documentation.

---

## A Secure and Governed Environment

Together, these administrative tools create a secure and well-governed environment where platform quality, compliance, and accountability are upheld at every stage. Platform Administration ensures that Forest Stack remains a trusted, scalable, and responsibly managed data and AI ecosystem.
